FireScrapling is an **open-source, self-hosted** orchestration layer for teams that
already pay Scrape.do or Scrapfly. Bring your own key, escalate fetch tiers only when
needed, and turn pages into LLM-ready Markdown.

There is no hosted SaaS by default (`HOSTED_MODE=false`). See [Hosted version?](/hosted).

## Why FireScrapling?

* **Credit-aware ladder** — local → static → JS → ASP → residential; domain memory ~24h.
* **BYOK** — your provider meter; keys encrypted at rest on your box.
* **Estimated savings** — vs always-ASP; see [Understanding savings](/fetch-savings).
* **Jobs, webhooks, MCP** — queue-backed scrape/crawl plus optional MCP tools.

Looking for a self-hosted [Firecrawl alternative](/comparison)? Read the honest
tradeoff page — when Firecrawl Cloud is the better fit, and when BYOK + escalation wins.
