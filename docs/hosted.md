# Hosted version?

FireScrapling ships **self-hosted** by default (`HOSTED_MODE=false`). There is **no**
public hosted SaaS tier today.

If you want a managed cloud offering (accounts, billing, platform keys), please +1 or
comment on the GitHub Discussion:

> https://github.com/firescrapling/firescrapling/discussions

(Create a “Hosted tier?” discussion at publish time and paste the URL here.)

Demand is tallied against [decision-gate.md](./decision-gate.md). Stars alone do not count.
