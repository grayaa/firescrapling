## Base URL

FireScrapling is self-hosted. Point clients at **your** instance — not a shared SaaS host.

| Setup | Typical base |
| :--- | :--- |
| Docker Compose (default) | `http://localhost:8000/v1` |
| Dashboard via nginx (`:8080`) | same origin: `http://localhost:8080/v1` |
| Your deploy | `https://<your-host>/v1` |

Swagger UI is at `/docs` on the API process (e.g. `http://localhost:8000/docs`).

## OpenAPI Specification

FireScrapling follows the [OpenAPI 3.1 specification](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.1.0.md). On a running instance:

- Interactive docs: `http://localhost:8000/docs`
- OpenAPI JSON: `http://localhost:8000/openapi.json`
- Hand-maintained YAML in the repo: [`apps/firescrapling/backend/openapi.yaml`](https://github.com/grayaa/firescrapling/blob/main/apps/firescrapling/backend/openapi.yaml)

Replace `localhost:8000` with your API host when you deploy.

## Authentication

Scrape/crawl/map endpoints require a `Bearer` **API key** (`fs_…`) in the `Authorization` header. Create keys in your local dashboard (Register → Login → API Keys) or via `POST /v1/keys` after `POST /v1/auth/login`.

```bash
-H "Authorization: Bearer YOUR_API_KEY"
```

Account routes (`/v1/keys`, `/v1/usage/…`, `/v1/providers`) use a **session token** from login, not the API key.

## Try it locally

1. Start the stack (`docker compose up --build`).
2. Open the dashboard (default `http://localhost:8080`) or Swagger at `http://localhost:8000/docs`.
3. Register the first user, create an API key, then call `/v1/scrape`.

There is no hosted playground that hits “our servers” — requests always go to the instance you run.

## Error Handling

FireScrapling uses standard HTTP status codes. Errors are wrapped as:

```json
{"error": {"code": "…", "message": "…", "request_id": "…"}}
```

| Status | Description |
| :--- | :--- |
| `200` | **OK**: The request was successful. |
| `202` | **Accepted**: The asynchronous job has been started. |
| `401` | **Unauthorized**: Invalid or missing API key / session. |
| `429` | **Too Many Requests**: Rate limit exceeded. |
| `500` | **Server Error**: An internal error occurred. |
