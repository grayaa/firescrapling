Follow these steps to integrate FireScrapling with your application.

## 1. Get an API Key

First, you'll need to create an account at the [FireScrapling Dashboard](https://dashboard.firescrapling.com) and generate an API key.

<Info>Keep your API key secure. It acts as your authentication for all requests.</Info>

## 2. Make your first `/scrape` request

Using cURL, you can quickly test the API by scraping a URL and getting clean Markdown back.

```bash
curl -X POST "https://api.firescrapling.com/v1/scrape" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://stripe.com/docs",
    "formats": ["markdown"],
    "onlyMainContent": true
  }'
```

## 3. Integrate with an LLM

Here's a simple example of how to use FireScrapling with OpenAI to answer questions based on a website's content.

```python
import requests
from openai import OpenAI

# Initialize clients
client = OpenAI(api_key="YOUR_OPENAI_KEY")
firescrapling_key = "YOUR_FIRESCRAPLING_KEY"

# 1. Scrape the content
res = requests.post(
    "https://api.firescrapling.com/v1/scrape",
    headers={"Authorization": f"Bearer {firescrapling_key}"},
    json={"url": "https://stripe.com/docs/api", "formats": ["markdown"]}
)
content = res.json()["data"]["markdown"]

# 2. Feed it to the LLM
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant. Use the provided context to answer questions."},
        {"role": "user", "content": f"Context: {content}\n\nQuestion: How do I create a customer in Stripe?"}
    ]
)

print(response.choices[0].message.content)
```
